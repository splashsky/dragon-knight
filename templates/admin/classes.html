Adding a class

Copy one of the files in app/content/classes/ to a new name (the file name is the class's key: lowercase letters, digits and _; it can't be changed later) and edit it. The class appears on the registration page on the next page load. Deleting a file retires its class: it is no longer offered, but characters of that class keep playing it. Run dk check to validate the files.

Items

Items are content files, app/content/items/<key>.lua; the game picks up a new or edited file on the next page load. Click an item to override its name, description, price, attack and defense, modifiers, drop settings and a consumable's power and messages on this server. What towns sell is edited with the towns (Edit Towns).

Adding an item

Copy one of the files in app/content/items/ to a new name (the file name is the item's key: lowercase letters, digits and _; it can't be changed later) and edit it. Give it a drop_level for monsters to drop it, or add it to a town's shop in Edit Towns. Deleting a file retires its item: shops stop selling it and monsters stop dropping it, but characters keep theirs (a retired consumable can't be used any more: what it does is its file's use function). Run dk check to validate the files.

Adding a spell

Copy one of the files in app/content/spells/ to a new name (the file name is the spell's key: lowercase letters, digits and _; it can't be changed later) and edit it, then list its key in a class file's levels[N].spells so characters learn it on reaching that level. Deleting a file retires its spell: characters who know it keep it, and class files can no longer list it. Run dk check to validate the files.

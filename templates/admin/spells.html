Spells

Spells are content files, app/content/spells/<key>.lua; the game picks up a new or edited file on the next page load. Click a spell to override its name, description, MP cost, power, icon and messages on this server; what it does is the file's code. Icons are PNG files in public/images/skills/ (default.png for a spell without one).

Adding a spell

Copy one of the files in app/content/spells/ to a new name (the file name is the spell's key: lowercase letters, digits and _; it can't be changed later) and edit it, then list its key in a class file's levels[N].spells so characters learn it on reaching that level. What a spell does is its cast function (see docs/APP.md, "Scripting spells and items"). Deleting a file retires its spell: characters who know it keep it but can no longer cast it, and class files can no longer list it. Run dk check to validate the files.
